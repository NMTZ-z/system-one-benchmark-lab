## 独立审查

Astra Medium 基于实际代码和原始离线证据独立审查，未修改文件，也未调用模型或 Provider。发现并修复了三项问题：

- 恢复入口缺失进程账本时，必须拒绝自动恢复。
- 成功裁决必须核验精确五个角色，不能接受只剩 preflight 的截断账本。
- H4E 只读账本锁必须非阻塞，避免锁等待阻止父进程进入超时清理。

对应反例测试已加入最终回归。该审查确认已读的原始离线记录符合 2 次 SDK、1 次 read、2 次本地 Completion 和规则 Retry。用户批准网络边界后，又对 Provider 策略、socket 审计和父子来源绑定进行了有界增量审查，无新增阻断项。

实际 Provider 策略测试通过：内核拒绝未获准端口，代理可读取获准文件并拒绝未获准文件；程序审计拒绝错误目标和 UDP，文件内容漂移触发阻断。外部保留地址仅用于 DNS 返回值和合成审计事件，没有外部 socket 连接。
